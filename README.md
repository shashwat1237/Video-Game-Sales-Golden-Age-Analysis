# Video Game Sales "Golden Age" Analysis
The aim is to predict the global sales of a video game.

The "Smart" Twist: This is another project where EDA and Storytelling are the stars. I use VGSales dataset to build a regression model, but then use my findings to build a narrative.
Answer questions like:

"Was there a 'golden age' of gaming? "

"Which publisher has the best 'hit rate' (highest avg. sales per game)?"


Core Skills: Regression, EDA, Data Visualization, Storytelling.
